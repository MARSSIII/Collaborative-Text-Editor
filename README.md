# Совместный текстовый редактор

Сетевое многопользовательское приложение для совместного редактирования текстовых документов в реальном времени. Несколько пользователей одновременно работают с одним документом, подключаясь к общему серверу. Каждый пользователь видит изменения и курсоры остальных участников мгновенно.
