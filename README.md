# Совместный текстовый редактор

Сетевое многопользовательское приложение для совместного редактирования текстовых документов в реальном времени. Несколько пользователей одновременно работают с одним документом, подключаясь к общему серверу. Каждый пользователь видит изменения и курсоры остальных участников мгновенно.

## Текущее состояние

Проект разделён на MVP и отложенные фичи (Phase 7). **Реализовано**: серверное ядро (бизнес-логика + сетевой слой) и полный набор тестов на бизнес-логику. **В плане (Phase 7)**: клиент на Qt 6, Undo/Redo, поиск/замена, rate limiting, API снапшотов, Viewer-роль, экспорт.

Подробный статус — в [docs/index.md](docs/index.md).

### Реализовано (MVP, серверная часть)

1. TCP-сервер на Boost.Asio принимает одновременные подключения, корректно обрабатывает отключения и уведомляет остальных участников документа.
2. Регистрация и авторизация по логину и паролю (хранение — in-memory, хеширование через `hash_utils`).
3. Создание документа, просмотр списка доступных документов, подключение/отключение, удаление (только Owner), управление правами Owner/Editor.
4. Каждый открытый документ обрабатывается в отдельном потоке. Входящие операции идут через lock-free MPSC-очередь и обрабатываются последовательно.
5. Автосохранение документов на диск в отдельном потоке с настраиваемой периодичностью.
6. Сбор и периодическая рассылка позиций курсоров — в отдельном потоке с батчингом.
7. Асинхронное логирование через lock-free MPSC-очередь.
8. Graceful shutdown с дренированием очередей и финальным сохранением.

### Логика редактирования

1. При подключении к документу пользователь получает полное актуальное содержимое и текущую ревизию.
2. Пользователь может вставлять и удалять текст в произвольной позиции. Локальные изменения применяются мгновенно (optimistic update).
3. Конфликты одновременного редактирования разрешаются через Operational Transformation (OT): каждая входящая операция трансформируется относительно всех операций, применённых после ревизии, на которой базировался клиент.
4. Свойство конвергенции: после применения всех операций содержимое документа идентично у всех подключённых пользователей.
5. Отмена (Undo) и повтор (Redo) — **Phase 7**.
6. Поиск и замена текста — **Phase 7**.

### Клиент (Phase 7)

Клиент на Qt 6 Widgets в активной документации описан, но не реализован. В Phase 7 планируются: окно подключения, список документов, редактор с нумерацией строк, отображение курсоров и выделений других пользователей уникальным цветом, боковая панель пользователей, строка состояния, экспорт в локальный файл.

## Технологический стек

- **Язык:** C++20 (`std::jthread`, `stop_token`, `std::atomic`, `std::shared_mutex`)
- **Сеть (сервер):** Boost.Asio (async TCP) + nlohmann/json, length-prefixed framing
- **Хранение:** in-memory структуры (пользователи, права доступа, метаданные) + текстовые файлы (содержимое документов, снапшоты, логи)
- **Тесты:** Google Test (подключается через FetchContent)
- **Сборка:** CMake ≥ 3.20
- **GUI (Phase 7):** Qt 6 Widgets
